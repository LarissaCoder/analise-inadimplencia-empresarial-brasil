# Análise da Inadimplência Empresarial no Brasil
Um projeto exploratório de SQL que investiga a inadimplência de empresas no Brasil



## 💡 Por que escolhi este tema?

Talvez não seja muito comum começar um projeto de análise de dados falando sobre a própria trajetória, mas quis fazer diferente no meu primeiro projeto prático.

Este projeto representa um marco na minha transição para a área de dados: o momento em que começo a transformar o que venho aprendendo em prática, explorando dados reais, levantando perguntas e buscando respostas que nem sempre são óbvias.

Trabalho na área comercial de uma empresa B2B que oferece software para contadores. A partir dessa experiência, comecei a olhar além dos clientes com quem tenho contato direto e a me interessar pela realidade das empresas brasileiras e pelos desafios que enfrentam para se manterem financeiramente sustentáveis.

O elevado número de empresas que encerram suas atividades no Brasil também despertou minha curiosidade. Comecei a pensar sobre as dificuldades financeiras que esses negócios enfrentam e sobre o que a inadimplência pode revelar a respeito desse cenário.

Foi assim que escolhi investigar a **inadimplência empresarial no Brasil**.

## 🎯 Objetivo

Investigar a evolução da inadimplência empresarial no Brasil, identificar padrões nos dados e compreender melhor as características desse cenário.

Este é meu primeiro projeto prático de análise de dados. Mais do que aplicar SQL, quero desenvolver minha capacidade de transformar dados em informações relevantes, conectando minha experiência profissional à minha nova trajetória na área de dados.
